각 단계 버튼을 눌러서 어디서 문제가 발생하는지 확인할 수 있어요.

← 지도로
STEP 0
현재 config.js의 API_URL
(읽는 중...)
⏳
STEP 1 — 웹앱이 살아있는지
Ping 테스트
action=ping 으로 응답이 오는지 확인합니다.
⏳
STEP 2 — "학생명단" 시트
학생 목록 불러오기
action=students 로 학생 이름들이 오는지 확인합니다.
⏳
STEP 3 — "진행기록" 시트 쓰기
테스트 기록 보내기 (POST)
학생="진단테스트", 미션=0 으로 한 줄을 기록합니다.
⏳
STEP 4 — 종합 통계
통계 불러오기
action=stats 로 학생 수 / 미션별 완료 수를 가져옵니다.
⏳
🛠️ 문제 해결 가이드 (자주 발생하는 오류)
❌ STEP 1 Ping 실패 (Failed to fetch / CORS)
  • config.js의 API_URL이 잘못되었거나 비어 있습니다.
  • Apps Script "배포"가 안 됐거나, 액세스가 "모든 사용자"가 아닙니다.
  • 해결: Apps Script 에디터 → 배포 → 배포 관리 → 톱니바퀴 ⚙️ → 버전: 새 버전 으로 수정 → URL은 그대로 유지됨.
❌ STEP 2 학생 목록 빈 배열 또는 오류
  • 스프레드시트 첫 시트 이름이 정확히 학생명단 인지 확인.
  • A열=번호, B열=이름, 2행부터 데이터.
❌ STEP 3 POST 실패
  • Apps Script가 "도메인 내 사용자"로 배포되어 있으면 학교 계정에서만 가능.
  • 해결: 배포 → "모든 사용자"로 변경 (혹은 학교 도메인 계정 유지).
  • "진행기록" 시트는 첫 기록 시 자동 생성됩니다.
❌ "권한 승인" 화면이 계속 나옴
  • Apps Script 처음 배포 시 권한을 승인해야 합니다.
  • "확인되지 않은 앱" 경고가 나오면 "고급" → "이름(안전하지 않음)으로 이동" 클릭.
⚠️ 새 배포 vs 배포 관리
  • 새 배포를 누르면 URL이 바뀝니다. 그러면 config.js의 API_URL도 업데이트해야 함.
  • 같은 URL을 유지하려면 배포 관리 → ⚙️ → 새 버전으로 코드만 갱신.
